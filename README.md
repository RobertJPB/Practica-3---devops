# Práctica 3: Automatización de Página Web (DevOps)

Página web estática "Hola Mundo" moderna con despliegue automatizado continuo (CI/CD) a **GitHub Pages**.

## 🌐 Enlaces del Proyecto

- **Repositorio:** [https://github.com/RobertJPB/Practica-3---devops](https://github.com/RobertJPB/Practica-3---devops)
- **Página Web en Vivo (GitHub Pages):** [https://robertjpb.github.io/Practica-3---devops/](https://robertjpb.github.io/Practica-3---devops/)

## 🚀 Automatización

El flujo de trabajo se encuentra configurado en `.github/workflows/deploy.yml`. Cada vez que se realiza un `git push` a la rama `main`, GitHub Actions construye y despliega automáticamente el contenido hacia GitHub Pages.
